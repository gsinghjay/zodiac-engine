## Project Overview

- **Type:** Monolith (single Python package `app/`)
- **Project type:** `backend` — FastAPI service **+ embedded server-rendered HTMX web UI**
- **Primary language:** Python 3.12
- **Architecture:** Layered (API → DI → Service → Integration)
- **Purpose:** Astrological chart generation, SVG visualization, tabular reports, and AI interpretation, wrapping the Kerykeion engine.

## ⚠️ Important findings at a glance

These came out of the exhaustive read — full detail in [architecture.md §8](./architecture.md#8-known-issues--gotchas):

1. **Web PNG/PDF/JPG download is broken** (`web.py download_chart` calls a non-existent method + misuses a `Literal`). Only SVG download works.
2. **`GET /` has two registered handlers** — the web landing page shadows the intended `/`→`/home` redirect.
3. **Orphan routers** (`composite`, `synastry`, `transit`) are defined but **not wired into the app**.
4. **Synastry interpretation is a stub**; only the **Gemini** LLM provider is implemented.
5. **`pytest.ini testpaths` is wrong** (`app/tests` doesn't exist) — run `pytest tests/`.
6. **Secrets in `.env`** (live-looking Gemini key) sit in the working tree; root logging is DEBUG.
7. **`docs/` is git-ignored** — this documentation won't be version-controlled unless `.gitignore` is updated.
